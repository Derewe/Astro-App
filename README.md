# Strovo App

A simple frontend prototype for Strovo, a platform for comparing construction material prices.

## Setup

1. Install Node.js from https://nodejs.org/
2. Run `npm install`
3. Run `npm run dev` to start the development server.

## Features

- Home screen with logo, slogan, search input, categories, and compare button
- Results screen listing suppliers with price, delivery time, rating, and select button
- Cart screen showing selected item, total price, delivery cost, and order button

UI uses dark theme with graphite background, yellow accent color, and white text.
